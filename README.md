# THE GENT'S ROOM

A responsive barbershop website built with HTML, CSS and JavaScript.

**Live Demo:** https://the-gents-room.netlify.app/

## About the Project

THE GENT'S ROOM is a fictional premium barbershop website created to demonstrate a professional online presence for a grooming business.

The website focuses on presenting services, showcasing work and making it easy for potential customers to find contact and booking information.

## Features

- Responsive navigation with a mobile hamburger menu.
- Hero section with a call-to-action button.
- About section introducing the business.
- Services section displaying available grooming services and prices.
- Gallery showcasing barbershop imagery.
- Contact section with business information and WhatsApp booking link.
- Responsive layout for desktop, tablet and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Netlify

## Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/eneojogodwinogah-code/the-gents-room.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the VS Code Live Server extension for local development.

## Deployment

The website is deployed using Netlify and connected to GitHub for automatic deployments.
